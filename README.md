# Müşteri Destek Talep Sistemi (Customer Support Ticket System)

Bu proje, Modern Yazılım Mühendisliği - Bulut ve DevOps dersi dönem projesi kapsamında geliştirilmektedir[cite: 2]. Müşteri şikâyet ve destek taleplerini yönetmek amacıyla kurgulanmıştır[cite: 3].

##  Temel Fonksiyonlar
1. **Talep Oluşturma (Create Ticket):** Yeni destek talebi kaydı açma[cite: 3].
2. **Talepleri Listeleme ve Filtreleme (Get/Filter Tickets):** Tüm talepleri ve öncelik durumlarını görüntüleme[cite: 3].
3. **Talep Durumu Güncelleme (Update Ticket Status):** Taleplerin durumunu (Açık, Devam Ediyor, Çözüldü) güncelleme[cite: 3].
