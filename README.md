# Müşteri Destek Talep Sistemi (Customer Support Ticket System)

Bu proje, Modern Yazılım Mühendisliği - Bulut ve DevOps dersi dönem projesi kapsamında geliştirilmektedir. Müşteri şikâyet ve destek taleplerini yönetmek amacıyla kurgulanmıştır.

##  Temel Fonksiyonlar
1. **Talep Oluşturma (Create Ticket):** Yeni destek talebi kaydı açma.
2. **Talepleri Listeleme ve Filtreleme (Get/Filter Tickets):** Tüm talepleri ve öncelik durumlarını görüntüleme.
3. **Talep Durumu Güncelleme (Update Ticket Status):** Taleplerin durumunu (Açık, Devam Ediyor, Çözüldü) güncelleme.

##  Teknoloji Yığını (Tech Stack)
* **Backend:** Node.js (Express.js)
* **Sürüm Kontrolü:** Git & GitHub
* **CI/CD Pipeline:** GitHub Actions
* **Konteynerleştirme:** Docker
* **Bulut Dağıtımı:** Render / Railway
